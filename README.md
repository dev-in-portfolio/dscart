# DSC ART — UrbanHippieArt Representation & Gallery

Public website repository for **DSC ART** — the artist representation and art-direction property of the Dark Star Ecosystem.

## Features
- **Contemporary Gallery Architecture**: Framing artwork with dark luxury aesthetic without competing with visual pieces.
- **Current Represented Artist**: UrbanHippieArt is the current artist represented by Dark Star Art.
- **Verified Official Link**: Direct connection to the UrbanHippieArt production portal (`https://uha.darkstarconsultinggroup.com`).
- **Acquisition & Representation Desk**: Dedicated intake path for art collectors, gallery curation, and artistic representation inquiries.

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```

Deployed via Netlify.

Public Art destination: `https://art.darkstarconsultinggroup.com`.
